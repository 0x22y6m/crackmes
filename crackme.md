## Recommended Tools

- Ghidra — static analysis and decompilation
- GDB — Linux dynamic debugging
- x64dbg — Windows dynamic debugging
- strings, file, readelf, objdump — initial triage
- Python — reproduce validation algorithms

## Rules for Every Challenge

1. Identify the file format and architecture.
2. Inspect strings and imports.
3. Find the input and validation functions.
4. Follow comparisons, arithmetic, loops, and conditional jumps.
5. Verify your findings in a debugger.
6. Write a short report explaining the algorithm.
7. Prefer understanding the original program over patching it.

**Important:** Challenge availability and ratings can change. Verify each listing before starting, and use an isolated VM when running downloaded binaries.
